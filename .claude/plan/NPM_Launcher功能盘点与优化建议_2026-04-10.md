# NPM Launcher 功能盘点与优化建议

## 当前已有功能

### 项目管理
- 添加/编辑/删除项目（名称、路径、启动命令）
- 项目拖拽排序、拖入/拖出文件夹
- 文件夹管理（新建/重命名/删除/排序）
- 项目收藏功能
- 右键上下文菜单（编辑/删除）

### 进程管理
- 启动/停止 npm 进程（`npm run <command>`）
- 实时日志流（stdout/stderr，自动解码 GBK）
- 进程状态追踪（running/stopped/error）
- Windows 进程树强制终止（taskkill）

### 终端
- 集成 xterm.js PTY 终端
- 复制粘贴快捷键（Ctrl+Shift+C/V、右键）
- 终端自适应容器大小

### Node 版本管理
- 显示当前 Node 版本
- nvm 已安装版本列表
- 切换 Node 版本（管理员提权）
- nvm 镜像源自动配置

### UI/UX
- 浅色/深色/系统 三种主题
- 自定义标题栏（跟随主题变色）
- 日志自动滚动
- 确认弹窗组件

## 发现的问题（可修复）

1. **终端切换丢失状态** — 切到日志 tab 时终端被销毁（v-if），shell 进程和历史全部丢失
2. **minNodeVersion 字段无用** — 存储了但从未校验，始终硬编码 `'16.0.0'`
3. **死代码** — `showTerminal` ref 声明未使用，`openTerminalWithCommand()` 从未调用
4. **残留 IPC** — `get-available-node-versions` 和 `install-node-version` 已暴露但无调用方
5. **错误提示用 alert()** — 切换 Node 版本失败用原生弹窗，体验差
6. **日志无虚拟滚动** — 大量日志时 DOM 节点过多会卡顿
7. **项目 ID 用 Date.now()** — 快速连续创建可能碰撞

## 建议新增功能（按实用性排序）

### 高价值（推荐优先）

1. **进程自动重启** — 项目崩溃后可选自动重启，支持配置重启间隔和最大次数
2. **全局快捷键** — 快速启动/停止选中项目（如 Ctrl+Enter 启动，Ctrl+Shift+X 停止）
3. **托盘最小化** — 关闭窗口最小化到系统托盘，进程继续后台运行
4. **通知提醒** — 进程崩溃/退出时发系统通知（Notification API）
5. **终端保持存活** — 切换 tab 时不销毁终端，保留 shell 历史

### 中价值（锦上添花）

6. **日志搜索/过滤** — 支持关键词搜索，按类型（stdout/stderr/error）过滤
7. **多项目批量操作** — 一键启动/停止所有项目，或某文件夹下的项目
8. **项目端口显示** — 自动检测项目监听的端口并显示
9. **package.json 脚本一键添加** — 从目录自动扫描并列出所有可用脚本，无需手动输入命令
10. **配置导入/导出** — 导出项目配置 JSON，方便在新电脑快速恢复

### 低价值（有时间再做）

11. **日志持久化** — 可选保存日志到文件，应用重启后可查看历史
12. **项目健康检查** — 检测项目路径是否存在、package.json 是否有效
13. **拖拽项目到文件夹的动画** — 改善拖放时的视觉反馈
14. **深色终端配色自定义** — 允许用户自定义终端颜色
15. **开机自启** — 可选开机自动启动应用

## 实施建议

**第一阶段（修复 + 核心体验提升）：**
- 修复终端切换丢失状态问题（v-if → v-show + keepAlive）
- 清理死代码和残留 IPC
- 加入全局快捷键
- 用 toast 通知替代 alert()
- 进程退出时发系统通知

**第二阶段（实用新功能）：**
- 托盘最小化 + 后台运行
- 进程自动重启
- 批量启动/停止
- 日志搜索过滤
