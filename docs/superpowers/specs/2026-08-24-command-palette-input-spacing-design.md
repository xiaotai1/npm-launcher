# 命令面板输入框留白优化设计

## 背景

命令面板输入框的局部样式将水平内边距覆盖为 `0`。输入框获得焦点时，光标和占位文字几乎贴着输入区域左边界，视觉上显得拥挤。

## 设计目标

- 为光标和输入文字提供适度的内部留白。
- 保持搜索图标、输入区域和关闭提示之间的现有布局关系。
- 不改变命令过滤、自动聚焦和键盘操作逻辑。
- 同时适配浅色和深色主题。

## 方案

将 `.command-palette-input` 的水平内边距由 `0` 调整为 `6px`，垂直内边距继续保持 `4px`。该数值能够改善光标贴边问题，同时不会明显压缩可输入宽度或拉大搜索图标与文字之间的距离。

本次不新增变量、组件或脚本逻辑，仅修改现有输入框样式规则。

## 验证方式

- 打开命令面板，确认输入框自动聚焦后光标与左边界存在自然留白。
- 输入中英文文本，确认文字起点与占位文字保持一致。
- 检查浅色和深色主题下的焦点样式与布局。
- 运行现有前端类型检查，不新增、修改或运行测试代码。
