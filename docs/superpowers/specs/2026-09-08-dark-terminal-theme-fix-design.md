# 暗色主题下交互终端背景修复设计

## 问题

应用从浅色主题切换到暗色主题时，主界面已经变暗，但交互终端仍保留浅色背景。

根因位于 `Terminal.vue` 的主题监听回调：回调先读取未声明的 `isUnmounted`，运行时抛出异常，导致后续的 xterm 主题和终端容器背景都没有更新。该代码由终端竞态修复引入，但遗漏了状态变量声明。

## 方案

在交互终端组件的生命周期状态附近声明 `let isUnmounted = false`。组件卸载时继续将其设为 `true`，主题监听回调继续使用该状态阻止卸载后的更新。

该方案保留现有竞态保护，只补齐缺失状态，不修改公共终端配色、不重构主题系统，也不影响运行日志终端。

## 数据流

1. 应用切换主题并更新根元素的 `data-theme`。
2. 交互终端的 `MutationObserver` 收到属性变化。
3. 组件仍挂载时，读取当前终端主题并同时更新 xterm 与外层终端背景。
4. 组件已卸载时，回调直接返回。

## 异常处理

沿用现有卸载保护，不新增额外异常分支。修复后，主题监听不会再因访问未声明变量而中断。

## 验证

- 运行现有类型检查，确认修改未引入 TypeScript 错误。
- 在浅色与暗色主题间切换，确认交互终端背景、文字和光标配色同步变化。
- 切换项目或离开终端视图，确认组件卸载时没有控制台异常。

根据项目约束，本次不新增、修改或运行测试代码。
