# 项目操作按钮悬浮提示修复设计

## 背景

项目上下文栏中的“打开项目目录”和“用 VS Code 打开”图标按钮同时使用了原生 `title` 属性与基于 `data-tooltip` 的自定义悬浮提示。鼠标悬浮时，两套提示会同时出现，导致文字重复，并且原生提示的位置无法由页面样式控制。

## 目标

- 每个图标按钮悬浮时只显示一份提示文字。
- 保留现有自定义提示的视觉样式与定位。
- 保留无障碍名称，不改变按钮点击行为。

## 方案

在 `ProjectContextBar.vue` 中删除两个图标按钮的 `title` 属性，保留：

- `aria-label`：继续为辅助技术提供完整的按钮名称。
- `data-tooltip`：继续作为现有 CSS 自定义提示的文字来源。
- 原有点击事件和图标：保持不变。

不引入新的 Tooltip 组件，也不修改其他按钮的提示方式，避免扩大本次修复范围。

## 验收标准

- 悬浮“打开项目目录”按钮时，仅显示一份“打开项目目录”。
- 悬浮“用 VS Code 打开”按钮时，仅显示一份“用 VS Code 打开”。
- 两个按钮仍可正常点击，并保留对应的 `aria-label`。
- TypeScript 静态检查通过。

## 验证方式

按照项目约束，不新增、修改或运行测试代码。完成修改后执行 TypeScript 静态检查与差异检查，并在开发页面中确认悬浮提示不再重复。
