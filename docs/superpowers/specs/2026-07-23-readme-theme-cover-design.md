# README 双主题封面设计

## 目标

为 NPM Launcher 的 README 增加一组不含本机隐私信息的产品截图，用浅色与深色主题共同展示应用质感，并让仓库首页更有吸引力。

## 展示方案

采用已确认的 B 方案：一张双主题组合封面作为 README 首屏 Hero。浅色界面位于左上，深色界面位于右下，两者轻微错位并带克制的层叠阴影。README 首段下方显示组合封面，并在封面下方提供浅色、深色原图链接，方便查看细节。

## 截图内容

- 使用项目总览页，突出状态统计、项目卡片和最近活动。
- 准备 6 个虚构项目，名称、命令与路径均不引用本机真实信息。
- 演示数据包含运行中、已停止和异常三类状态，使界面信息完整但不过度拥挤。
- 浅色和深色截图使用相同的数据、窗口尺寸与滚动位置，确保对比一致。

## 输出资源

- `docs/images/npm-launcher-light.webp`：1600×900 浅色主题原图。
- `docs/images/npm-launcher-dark.webp`：1600×900 深色主题原图。
- `docs/images/npm-launcher-cover.webp`：README 使用的双主题组合封面。

所有图片优先使用 WebP，在保持文字可读的前提下控制仓库体积。

## README 排版

组合封面放在项目简介之后、功能特性之前，使用居中 HTML 图片标签限制最大显示宽度，并提供有意义的替代文本。封面下方使用居中的“浅色原图 · 深色原图”文字链接访问两张截图，避免 README 首屏连续堆叠三张大图。

## 生成与验证

1. 使用隔离的演示配置启动应用，不覆盖用户现有 Electron 配置。
2. 分别切换浅色、深色主题并截图。
3. 合成组合封面，不改变应用 UI 本身。
4. 检查截图中不存在真实路径、用户名、通知或其他本机信息。
5. 验证图片尺寸、WebP 可读性、README 引用路径和 Markdown 渲染。

## 范围边界

本次只新增 README 展示资源与相关文案，不修改应用 UI、业务功能或用户配置。
