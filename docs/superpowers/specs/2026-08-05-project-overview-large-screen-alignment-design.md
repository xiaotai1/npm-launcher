# 项目总览大屏对齐修复设计

## 问题

项目总览顶部统计区使用三等分网格，主体区使用左侧项目区与右侧信息栏的 `3:2` 两列布局。左侧项目区当前采用自动填充列，当窗口变宽后会自动扩展为两列，导致项目卡与“添加项目”横向排列，与正常窗口下的纵向布局不一致。

## 目标

- 保持顶部三张统计卡片的三等分布局。
- 保持主体区左侧项目区、右侧信息栏的 `3:2` 布局。
- 项目卡与“添加项目”在左侧始终按单列纵向排列，不因大屏宽度自动增列。
- 保留现有窄屏响应式行为。

## 实现

仅修改 `ProjectOverview.vue` 中 `.project-grid` 的列定义，将自动填充列改为固定单列 `minmax(0, 1fr)`。不修改组件结构、数据流、交互逻辑和其他视觉样式。

## 验证

- 运行现有类型检查或构建检查，不新增、修改或运行测试代码。
- 在正常窗口与大屏窗口下检查项目卡和“添加项目”均为纵向排列。
- 检查右侧运行时、会话等信息栏仍处于主体右列。
- 检查页面无横向滚动和内容重叠。

## 风险

改动仅影响项目总览左侧项目列表的列数。大屏下会减少同屏横向展示数量，但这正是参考界面要求的稳定布局。
